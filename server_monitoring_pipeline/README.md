# Virtual Server Monitoring Pipeline
This project demonstrates a server monitoring data pipeline built using Python and Power BI.
The pipeline ingests server log data from a CSV file, performs data cleaning and transformation, and visualizes key server performance metrics using an interactive Power BI dashboard.

# Dataset
server_logs.csv

# Columns:
- Server_ID
- Timestamp
- CPU_Usage
- Memory_Usage
- Disk_IO
- Network_IO
- Server_Location
- OS_Type
- Instance_Size

# Data Pipeline

Step 1: Data ingestion from CSV
Step 2: Data cleaning and preprocessing
Step 3: Feature engineering
Step 4: Data storage in Azure SQL / Data Lake

# Power BI Dashboard

Visuals Included:
- CPU Utilization Trend
- Memory Usage Analysis
- Server Uptime
- Resource Utilization

# Tools Used

- Python
- Azure Data Lake / Azure SQL
- Power BI
- Pandas
